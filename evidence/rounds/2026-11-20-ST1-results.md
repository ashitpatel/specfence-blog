## Design notes (deviations and fences)

- **Round code ST1, not SC1:** SC1 was taken (2026-11-02 below-screen round;
  `mutate_sc1.py` already existed and is untouched). ST2–ST4 follow.
- Reachability bound: an op is invocable when called in-tree (resolved targets)
  or public; sequence adjacency of consecutive ops is explicitly `not_checked`.
  Library-public methods pass; only private-and-uncalled is uncertain (F3).
- Refutes need zero unknowns: any `uncertain` check beats a `refuted` one.
- `structural defect` faces no evidence-policy bar beyond its confirmation
  (nothing stronger exists under static scope); WD1 protection is automatic via
  the "statically confirmed" evidence level.
- Frame parsing anchors ``s2.f = s.f`` to end-of-line/`and`, so
  ``s2.items = s.items + e`` (a change) never reads as framed.
- Python-first: mapping/reachability read `facts.functions` accesses/calls;
  Java/Go/Node parity rides ST3.2/ST4.4.
