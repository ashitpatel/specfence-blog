# ST6 plan: close the Alloy remainder (2026-11-20)

Relevance (checked 2026-11-20 before writing; the tree moved since ST4):
still open: subscript-mutator writes, T12 (re-diagnosed: structure/ST1
attribution, not the index), M5 review detection, blind eval, ST1 fences.
Still blocked: ST3.2 ports (extractors unchanged; tree-sitter carries JS/TS
only — no Java/Go statement shapes; verified, not assumed). Closed as
designed: Django `?`-targets (partial-tree cause: `ModelWithMetadata` and
`VoucherCode` live outside the 4-apps tree; `?` is the honest mark).

## What changes

- **ST6.1 subscript writes** (`index/concurrency.py`): a mutator call on a
  subscript receiver (`self.d[k].add(v)`) records the container write
  (today: read-only). Fixes T11's false refute and the missed temporal
  races through the same shape. Blast radius: race proposals may grow;
  neighbor suites + full suite gate it.
- **ST6.2 subclass writers**: `python_structural` attributes same-file
  subclass methods writing inherited fields (T12's shape); ST1's
  `_class_states` collects by accessed-state owner instead of function
  prefix (external readers confirm existence — sound direction).
  Oracle re-verify: T12 flips eligible (predicted), no real lost.
- **ST6.3 M5 detection** (`review/touched.py`): a base structural proposal
  whose class the change touches but head no longer proposes is reported
  under `vanished` (structural only: temporal regroups routinely).
- **ST6.4 ST1 fences**: (a) stutter steps attribute to all-frame ops, plus
  a soundness dual (a framed field the method writes is uncertain);
  (b) variant ops map by suffix-strip (`Op_X_throw` → `X`, ambiguous →
  uncertain, named in the reason); (c) partial-path methods (more writes
  after an await than the op claims) record an explicit `assumptions`
  entry (async only; sync calls stay out — would spam).
- **ST6.5 blind eval + re-ablation rule**: 3 unseen trees
  (aiokafka pkt-a, recall-java-sshd, recall-go-etcd), top-5 structural
  each, labels frozen before scoring. Predictions: precision in
  [0.10, 0.40] on the fenced engine; ≥1 new real. Re-ablate iff total
  positives ≥ 5 (leave-one-tree-out, ships only on improvement);
  otherwise deferred-again with the new numbers.

## Tests and mutants

- Index unit tests (subscript mutators incl. `del`/`pop`/`setdefault`);
  subclass-writer + owner-states tests; M5 review test (mutate-then-review
  a joint write away); omission/variant/assumption fixture tests
  (M4 must confirm; T5 keeps its id without rename).
- `mutate_st6.py`: subscript-read (write dropped), subclass-blind,
  vanished-silent, stutter-unattributed, variant-unmapped,
  assumption-silent. Each kills via the new tests.
- Full suite at the end (background); the index change makes this gate
  load-bearing — any race-count movement in existing tests is investigated,
  not bulk-updated.

## Not in scope

- ST3.2 ports (still blocked, verified), Django `?` (designed),
  string content, full semantics, dynamic replay, None-flow drift.
