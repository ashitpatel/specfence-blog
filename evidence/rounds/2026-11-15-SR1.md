thread or loop, the race is not real, so do not file it". Later sections say that callback or task orderings on one
loop are real bugs, and never a reason to skip one. The rule now says:
- one **thread** means the race is not real;
- one **loop** is different: its order can still be a bug, to be modelled under "A project event loop" or "One event
  loop", and never dropped.

This has the same shape as run 25's skip (SL1's H3), where an agent dropped a reactor slice as single-threaded.

engine accepts (`survey/slices.py`, line 274). model-slice and the `choose_slices` tool description left the direct
call out. Both now name it.

inside the numbered steps, so steps 2 to 4 sat under it. It now comes at the end, as "Reference: answers written
before the run". Step 1 ends with a pointer to it.
