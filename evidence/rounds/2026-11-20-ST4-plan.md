# ST4 prereg: corners + scale verdict (2026-11-20)

- **Why now:** the last phase of the approved ST1–ST4 plan: ORM/schema corners,
  review-time cite freshness, Go parity, and the scale verdict ST3.1's
  coverage miss reframed (hand-writing stays the bottleneck).
- **Go:** the owner's `go` plus full-autonomous mode.

## What changes

- **ST4.1 SQLAlchemy schemas:** `_sqla_tables` in `datamodel/schema.py`: tables
  from declarative models (classic `Column` and 2.0 `mapped_column` styles):
  `__tablename__`, column types, `primary_key`/`nullable`/`unique`,
  `ForeignKey("t.c", ondelete=...)`, `__table_args__` (`UniqueConstraint`,
  `CheckConstraint` with `IN` only). Precedence: SQL > Django > SQLAlchemy.
- **ST4.2 drift asserts:** one decidable shape — `.one()` (SQLAlchemy) /
  `.get()` (Django) on a column set with no UNIQUE covering it (single or
  composite): the code assumes at-most-one, the schema does not enforce it.
  New `DataModelFinding` kind, wired into the data-model Alloy check.
- **ST4.3 boundary doc:** enums-as-atoms in, regex/length/content out —
  recorded in the datamodel module docstrings (the fence, not a TODO).
- **ST4.4a cite freshness:** review flags `.als` `-- @code` refs that no
  longer resolve in the head index (renames/deletes), where today nothing
  checks (`code_symbols=None`).
- **ST4.4b Go parity:** propose → skeleton → check → confirm end to end on a
  Go tree. ST1's confirm reads `facts.functions` directly; if Go facts lack
  that shape the gap is recorded precisely instead of papered.
- **ST4.5 scale verdict:** agent-minutes accounting from ST2–ST3 + the
  depth-2 verdict on measured numbers. Analysis, no code.

## Predictions (fixed now; mechanism-level, no risky thresholds)

- SQLAlchemy classic + `mapped_column` fixtures each yield their tables,
  columns, one FK and one composite unique; SQL/Django keep precedence on
  clashes (fixture).
- The drift assert fires on a fixture calling `.one()` over a non-unique
  column set and stays silent with the UNIQUE present (both ORMs).
- Review flags a renamed `@code` symbol and stays silent when all resolve.
- Go parity: if `facts.functions` exists for Go, the translated F1 confirms;
  else the record names the missing shape. Either outcome is reported, not
  graded.
- Scale: depth-2 stands or moves on ST2–ST3 numbers (precision 2/10 fenced,
  coverage ~0.03, minutes-per-model measured here).

## Tests and mutants

- `tests/test_datamodel_sqla.py` (styles, precedence, drift +/-), review
  freshness tests, Go parity test if the shape exists (else a test pinning
  the refusal/gap).
- `mutate_st4.py`: nullable inversion, unique-dropped, freshness-blind.
- Full suite green at the end; no temporal regression.
