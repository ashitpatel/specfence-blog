# AF1: the answers file counts in the code mode only when the run began with it

- **The hatch:** CM1 row A2 (`2026-11-15-CM1-results.md`). In the code mode, an answers file the agent writes itself
  settles several kinds of answer, and the first-look report never names the file:
  - the deployment dimensions, and the model's confirmation;
  - sharing, usage and loop threads;
  - options, progress, failures and scope.
- **The owner's decision:** "Strict freeze + list (Recommended)" (`decisions/2026-11-15-owner-decisions-af1.md`).

## What changed

**The loader.** `deploy/answers.load_answers_file` returns None, so that nothing in the file is read, unless the file
counts. Every code-mode reader goes through it:
- the deployment store;
- `QuestionAnswers` (sharing, usage, options, progress, failures, scope and loop threads);
- `unlisted_default`;
- the temporal answers.

RF1's audited scenario acceptance reads it with `frozen=False`, and is unchanged.

**When the file counts** (`forge/frozen.file_counts`): `begin_run` or the person froze it, and its bytes are the same
as at the freeze.
- **The person's freeze command** is `python -m specfence_engine.forge.frozen <root>`. Its record says
  `source: person`; `begin_run`'s record says `source: begin_run`.
- **A record is never replaced,** as in RF1.

**A read before any freeze** records `source: first-read`, and the file never counts under that record. So an agent
cannot write the file, let a tool read it, and then call `begin_run` to freeze it.

**What the person sees** (`survey/report.py`):
- `first_look_report` has an `answers_file` block:
  - when the file was not read: `present`, `read: false` and `why_not`;
  - when it was read: the client and every answer the file gave.
- `approvals_open` gains the line "answers file not read: <why>".

**A latent RF1 defect, found and fixed.** `begin_run` returned "returning" before it froze anything whenever an
answers file was already present, because `run_state` counts the file as run state. So the person's pre-placed file
was never frozen. RF1's tests had called `freeze` directly, so they never saw it. The freeze now comes before the
returning check.

**The skills:**
- `start` step 0 says to call `begin_run` first whenever an answers file is present;
- first-look's answers-file section states the freeze, marked **checked**, and says to show the person
  `answers_file.answers`.

## M-mech

The tests are in `tests/test_af1_answers_frozen.py` (9 tests). CM1's row A2 in `tests/test_code_mode_hatches.py` now
asserts closed. `tests/test_forge_frozen.py` was changed for two intended behaviour changes:
- tests that build provenance from a file the run did not begin with pass `frozen=False`;
- the freeze record carries `source`.

**The tests that place a file.** Twelve test files had placed a person's file without freezing it. They now call
`tests/answers_helper.person_froze`, which stands in for the freeze command at placement. The loader validates the
file before it checks the freeze, so a malformed file is still refused, frozen or not. The first build checked the
freeze first, and the malformed-file tests caught it.

**The mutation check:** `tools/dev/af1/mutants.py`, on a copy of `src`, with CM1's runner. **7 of 7 caught, with a
clean control.**

## Limits

- **A file the agent writes before `begin_run`, with no specfence read in between, is still frozen as the person's.**
  This was RF1's limit, and it stays. Telling the person's file from one the agent wrote before any tool ran needs
  something the agent cannot write, such as the signed driver envelope.
- **Runs that skip `begin_run` lose the file entirely.** That includes earlier clean-room harnesses, which placed the
  file without freezing it. Their questions stay open, which fails safe, but a run that relied on the file gets open
  questions instead. Future clean-room harnesses must run the freeze command when they place the file.
- **A changed file is not read at all,** not even its unchanged answers. A person who edits the file mid-run has to
  start a fresh run, as in RF1.
- **No agent trial was run.**
