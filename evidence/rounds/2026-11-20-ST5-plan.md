# ST5 prereg: structural visibility (report + attrs + docs) (2026-11-20)

- **Why now:** ST1–ST4 built the machinery but left it half-visible: filed
  structural defects appear nowhere in the first-look report, attrs/dataclass
  state has no skeleton, and the manual documents none of it.
- **Go:** the owner's `go` on the ST5 proposal (report integration + attrs
  fields + docs).

## What changes

- **ST5.1 report:** `survey/report.py` lists `structural defect` findings in
  section 1 with the bugs, labelled (the deterministic-defect precedent),
  and `_explained` keys them by (subject, property) so counterexamples they
  already report are explained, not re-reported.
- **ST5.2 attrs fields:** `_fields_and_ops` (`skeleton/alloy.py`) reads
  `@attrs.define`/`@attr.s`/`@dataclass` class-level annotations when
  `__init__` assigns nothing: `list`/`set`/`dict`/`int` (+ `typing`/`X | None`
  spellings) classify as relation/map/int; anything else is an omit-note, not
  a guess. `__init__` assigns keep precedence on clashes.
- **ST5.3 docs:** the user manual documents `confirm_alloy_instance`, the
  `structural defect` status, the ST3.0 fences, and extraction (what shapes,
  the measured ~0.03 coverage, the soundness rule).

## Predictions (fixed now)

- An F1-shaped structural defect filed on a fixture tree appears in
  `1_bugs` with a structural label, and a second counterexample on the
  same (subject, property) is explained by it (not duplicated).
- Attrs fixtures: annotated containers/int derive; a class with neither
  assigns nor annotations still refuses; non-attrs behavior byte-identical
  (existing skeleton tests unmodified and green).
- Docs: the four items each named at least once in `docs/user-manual/`
  (mechanical grep check).

## Tests and mutants

- Report label/key tests (fixture tree, no solver); attrs fixture tests
  (three decorator spellings + Optional/union); `mutate_st5.py`:
  label-blind (structural defect unlabelled/missing), attrs-ignored
  (annotations skipped).
- Full suite at the end (background); no temporal regression.

## Not in scope
