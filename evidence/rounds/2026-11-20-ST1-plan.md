## What changes

- **ST1.1 (mapping).** New `src/specfence_engine/confirm_alloy.py`:
  `confirm_alloy_instance(index, model_path, check_label)` runs `check_alloy`,
  takes the violating command's instance, resolves every atom/field through the
  model's `-- @code` tags to index symbols. Any unmapped atom ⇒ `uncertain`
  naming it. No counterexample (assert holds) ⇒ refusal ("nothing to confirm").
- **ST1.2 (steps).** Each `Op_` step in the violating trace must map to a method
  the code defines, writing fields the code writes, in an order the CFG permits
  (bound: same function or a direct call; beyond the bound ⇒ `uncertain`).
- **ST1.3 (verdicts).** `confirmed` (all atoms mapped, all steps reachable);
  `refuted` (a mapped step contradicts the indexed code: field never written
  anywhere, guard makes the state impossible — closed-world over the index,
  stated in the reason); `uncertain` (default). No `by_runtime`: structural
  verdicts are runtime-independent. Scope + bitwidth in strength bounds.
- **ST1.4 (wiring).** MCP tool `confirm_alloy_instance`; `report_finding` status
  `structural defect` citing the confirmation id (a new terminal status; `bug`
  keeps its race/repro semantics); skill MUSTs with named checks in
  `alloy-authoring.md` + the `model-slice.md` depth route; `skill_lint` clean.

## Predictions (fixed now; fixtures carry them)

- F1 (mapped + reachable violation) ⇒ `confirmed`.
- F2 (an instance atom with no `-- @code` path to the index) ⇒ `uncertain`
  naming the atom.
- F3 (a trace step through an op the code never calls) ⇒ `uncertain`
  (beyond the reachability bound).
- F4 (violation needs a write to a field nothing in the index writes) ⇒
  `refuted`, reason stating the closed-world assumption.
- F5 (a guard in code makes the violating state impossible) ⇒ `refuted`.
- F6 (assert holds: no counterexample) ⇒ refusal, with a negative test.
- Mutants (each must flip a fixture verdict or be refused): drop one atom
  mapping; flip one reachability answer; widen the scope silently (strength
  must carry the scope the verdict rests on).
- **Confirm-rate gate (evaluated on the ST2 case set, fixed now):** of the
  violations whose atoms all map, ≥50% confirm; and every `confirmed` must
  survive hand-reading (confirmed-precision 100% on the hand-read sample —
  false confirmeds are the unforgivable error, false uncertains are acceptable
  under prefer-FP). Missing the rate narrows the claim to mapping-level
  confirmation; it never weakens the bound silently.
